# Hackathon Submission Copy

## Project Name
StudyMate AI Pro V2 — Autonomous Multi-Agent Learning System

## Brief Description
StudyMate AI Pro V2 is a RAG-grounded autonomous learning platform that turns
uploaded study material into a quality-controlled learning module through a
visible multi-agent workflow. An Architect Agent creates a prioritized 3-day
syllabus, an Examiner Agent automatically generates a syllabus-bounded
assessment, and a QA Critic cross-checks both artifacts for scope errors,
hallucinations, ambiguity and answer-key consistency before correcting and
certifying the final module. The system also supports multimodal study inputs,
RAG chat, PDF/Markdown export, audit logs and adaptive revision guidance.

## Skills Demonstrated
Generative AI; Agentic AI; Multi-Agent Systems; AI Workflows; AI-powered
Business Process Automation.
